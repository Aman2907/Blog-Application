# ✍️ thinkNwrite — Blog & Article Writing Web App

![thinkNwrite](https://github.com/Aman2907/Blog-Application/assets/74008888/b885db73-8e33-41f8-b37c-3de3e7bab6a4)

## 🌟 Overview

**thinkNwrite** is a modern blog and article-writing web application designed for writers, bloggers, and content creators. It allows users to create, publish, edit, and delete rich blog posts with custom images.

Whether you're sharing personal thoughts, writing professional articles, or documenting your ideas, thinkNwrite provides a simple and user-friendly platform to manage your content.

## 🚀 Main Features

* New users can **Sign Up** and create an account.
* Existing users can **Log In** securely.
* Create and publish your own blog posts.
* Add custom images to your blog posts.
* Edit previously published blogs.
* Delete blogs with confirmation.
* Store application data securely using **MongoDB Atlas**.
* Secure authentication using **JWT and bcrypt**.

## 🔑 Key Features

### 👤 User Authentication

* New users can **Sign Up** to create an account.
* Existing users can **Log In** to access their dashboard.
* Passwords are securely hashed using **bcrypt**.
* User authentication and authorization are handled using **JWT**.

### 📝 Create Blogs

* Write and publish your own blog posts.
* Add custom images to your articles.
* Create rich and engaging content through a simple interface.

### ✏️ Edit & Delete Posts

* Edit your previously published blog posts.
* Delete unwanted posts.
* A confirmation prompt is displayed before deleting a blog.

### ☁️ Data Storage

* Blog and user data are stored securely in **MongoDB Atlas**.
* The backend uses **Node.js** and **Express.js** to handle APIs and database operations.
